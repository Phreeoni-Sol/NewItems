# Sources de référence pour Claude

Les versions exactes, URLs et licences sont dans `upstream/provenance.json`.
Les deux archives Git sont des exports des fichiers suivis au commit épinglé :
elles contiennent les sources et licences, mais aucun dossier `.git`.
Extraire dans `work/upstream/` pour les consulter. Les outils qui demandent
`git rev-parse HEAD` exigent un véritable checkout au commit indiqué ; un export
ZIP ne remplace pas un dépôt Git.

Les extraits d'Ivalice Companion sont une référence partielle, non compilable,
sous GPL et avec leurs notices conservées. Ils ne sont pas incorporés dans la
bibliothèque ExtensionCore. Conserver cette séparation ; vérifier la licence
avant toute réutilisation de code. Aucun exécutable du jeu, archive PAC,
échantillon NXD ou sauvegarde personnelle n'est livré dans ce dossier.
