# Bibliothèque de développement

`ForgottenJobs.ExtensionCore.dll` contient redirection transactionnelle de tables, adaptateur mémoire Windows, routage de commandes, projection de menu et progression séparée.

**Pas d'entrée Reloaded, pas de hooks du jeu installés, pas de job jouable.** Source et preuves : `docs/runtime-extension.md`, `runtime/ExtensionCore/`, `tests/`.

54 contrôles du cœur réussis ; lecteur natif copié testé sur 5 632 couples commande/emplacement. Tests dans de la mémoire appartenant aux fixtures ; aucun patch du jeu ni sauvegarde utilisateur modifiée.
